# 元宝搜索接口规则（本项目强制约束）

> 状态：生效
> 适用对象：YuanBaoSearch 仓库内所有调用元宝搜索（腾讯云 wsa）的代码、脚本与 Agent 行为。
> 权威依据：《腾讯云元宝搜索产品接入指引.md》（`D:\Develop\YuanBaoSearch\腾讯云元宝搜索产品接入指引\`）、腾讯云官方文档（产品官网 <https://cloud.tencent.com/product/wsa>）。
> 赛道要求依据：`docs/侦探赛道要求.md`。

---

## 一、接入前提

1. 必须使用腾讯云账号开通「元宝搜索」服务（控制台：<https://console.cloud.tencent.com/wsapi/index>），计费模式为**后付费**，开通前账户余额需 ≥ 0 元。
2. 版本选择：极速版 / 标准版 / 旗舰版三选一，30 分钟内仅可切换一次版本；个人实名账号支持极速版、标准版；旗舰版仅限企业认证账号。
3. 鉴权方式二选一：
   - **腾讯云标准方式**：SecretId + SecretKey（TC3 签名），密钥在 <https://console.cloud.tencent.com/cam/capi> 创建；
   - **服务 API KEY 方式**：单 API KEY 认证，每个账号最多同时持有 3 个服务密钥。
4. 密钥创建时仅展示一次明文，后续不可查询；保存与使用规则见下文「七、密钥与安全」。

## 二、接口调用规则（硬约束）

| 项目 | 取值 |
|---|---|
| 服务标识 | `wsa` |
| 版本（Version） | `2025-05-08` |
| 接口（Action） | `SearchPro` |
| Endpoint | `wsa.tencentcloudapi.com` |
| 请求方法 | POST |
| 返回格式 | JSON |

### 入参规则

- `Query`：**必填**，检索词。
- `Mode`（仅标准版使用，可省略）：
  - `0`：自然结果；
  - `1`：VR 卡（优质权威垂直信源）；
  - `2`：自然结果 + VR 卡。
- 旗舰版无需传 `Mode`，命中 VR 卡时自动展现。
- 其余参数可选，按官方接口文档补充，**不得传未定义的参数**。

### 出参处理规则

- 结果在 `Response.Pages`，每条为 JSON 字符串，常用字段：`title`、`url`、`site`、`passage`、`date`、`score`；VR 卡额外含 `vr: true`、`vr_category`、`vrid`。
- **来源字段（url）必须保留并原样透出**，禁止改写、替换或丢失。
- 结构化输出到用户面前时，至少包含：`结论` + `依据（passage 摘要）` + `来源（可点开 url）`。

## 三、输出组织规则（对齐赛道评审）

1. 每次查询回答的格式固定为「结论 + 依据 + 来源」，来源必须可点开。
2. **查不到就明确说不知道**，禁止用模型内建知识冒充搜索结果，禁止编造 url、标题或数据。
3. 多个来源冲突时，优先展示权威信源（VR 卡结果优先），并标注信息时效（date）。
4. 展示检索结果时注明来源站点与时间，便于评委溯源。

## 四、限流与错误处理

- QPS 限制：极速版 20、标准版 20、旗舰版 5。
- 常见错误码以腾讯云公共错误码与元宝搜索错误码为准（见接入指引），处理策略：
  - 限流（429 / 限流码）：指数退避重试，最多 3 次，退避间隔 1s、2s、4s；
  - 鉴权失败：停止调用并提示密钥问题，不重试；
  - 参数错误：按错误提示修正后重试 1 次；
  - 余额不足：停止调用并告警，不静默失败。
- 任何失败不得向用户展示"假结果"或空结果冒充成功。

## 五、额度与成本控制（6000 次预算）

- 活动期侦探赛道选手每月 **6000 次免费调用**（活动结束恢复 2000 次/自然月/UIN）。
- 强制节约策略：
  1. 相同查询命中结果后，结果缓存本地（建议 TTL ≥ 10 分钟），重复问题优先读缓存；
  2. 演示与测试优先用 3 次真实查询的固定用例，不反复发起相同请求；
  3. 批量任务分批执行，单批不超过 20 次查询，批间间隔 ≥ 1 秒；
  4. 记录每次调用的 Query、时间、是否命中缓存，便于对账与审计（日志落盘到 `docs/` 或运行日志目录，不含密钥）。
- 超出 6000 次后立即停止自动调用，向用户报告剩余额度，不得欠费超支。

## 六、搜索质量与题材红线

1. 查询输入层过滤：**不碰时政、不涉及个人隐私消息**，涉及时政或个人信息的 Query 直接拒绝并提示换题。
2. 输出层过滤：检索结果命中时政、个人隐私、违法违规内容时，不展示、不转发、不加工。
3. 谣言类传言核查场景：只呈现可溯源的事实与来源，不下未经证实的结论。

## 七、密钥与安全（最高约束）

1. SecretId / SecretKey / API KEY **禁止硬编码进代码**，禁止提交到仓库，禁止在对话、日志、文档中明文输出。
2. 一律通过环境变量或本地配置文件（`.env` / 用户级配置）注入，`.env` 须加入 `.gitignore`。
3. 密钥文件权限最小化；泄露风险发生时立即到控制台轮换密钥。
4. 子账号调用需先由主账号在访问管理控制台授予元宝搜索（WSA）权限。

## 八、进阶挑战的接口使用要求（选做，明显加分）

- **深度调查**：同一调查主题拆分为多轮 `SearchPro` 查询，不同 Query 交叉比对，输出带证据链的调查报告，每条结论挂来源；
- **持续盯梢**：按固定周期轮询同一 Query 的最新结果，比对 date/内容变化，有变化时提醒；
- **截图查证**：先对截图/视频中的说法做文字识别，再以识别出的实体或说法作为 Query 发起检索，输出"识别内容 + 检索结论 + 来源"。

## 九、快速验证

- API Explorer 在线调用（等同真实调用，会收费）：<https://console.cloud.tencent.com/api/explorer?Product=wsa&Version=2025-05-08&Action=SearchPro>
- 最小示例（Python，仅演示结构，密钥须替换为环境变量）：

```python
import os
import json
from tencentcloud.common.common_client import CommonClient
from tencentcloud.common import credential
from tencentcloud.common.profile.client_profile import ClientProfile
from tencentcloud.common.profile.http_profile import HttpProfile

cred = credential.Credential(os.environ["TENCENTCLOUD_SECRET_ID"],
                             os.environ["TENCENTCLOUD_SECRET_KEY"])
http_profile = HttpProfile()
http_profile.endpoint = "wsa.tencentcloudapi.com"
client_profile = ClientProfile()
client_profile.httpProfile = http_profile

client = CommonClient("wsa", "2025-05-08", cred, "", profile=client_profile)
params = json.dumps({"Query": "三星堆", "Mode": 0})
print(client.call_json("SearchPro", json.loads(params)))
```
