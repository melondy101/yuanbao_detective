# 正式录屏脚本（2026-10-25）

> 用系统浏览器（Edge/Chrome）+ 系统录屏（Win+G 或 OBS），窗口全屏、缩放 100%。
> 录制目标：证明「真实查询 → 有结果 → 来源点得开」。总时长控制在 3~5 分钟。
> 优先在 Vercel 部署后的线上地址录制（更有说服力）；部署未就绪时用 `npm run dev` 的 http://localhost:3000，脚本通用。

## 镜头 1：首页与链路自检（约 20s）

- 打开首页，停留展示：左侧窄栏导航（01 深度调查 / 02 持续盯梢）、印刷档案风界面。
- 顺带访问 `/api/smoke`，让评审看到 `ok:true` 与结果数。

## 镜头 2：深度调查——真实查询①（约 60~90s）

- 输入：`罗小黑战记2 院线票房`，点击开始。
- 录到：拆题子问题逐个出现 → 并行搜索进行中 → 三分法报告生成。
- **关键动作：报告出来后滚动到「来源」区，实际点开 1~2 条来源链接**，展示新标签页打开真实网页。
- 指出：置信徽章、时效徽章、每条结论都挂锚点。

## 镜头 3：深度调查——真实查询②（约 40s，可加速）

- 输入：`腾讯元宝搜索 和 传统搜索引擎 区别`（或演示留痕里的「AI线上活动」题）。
- 报告生成后快速展示来源区即可，不必再点开。

## 镜头 4：红线拒绝（约 15s）

- 输入一个时政类问题（用测试时同类问法），展示礼貌拒绝与指引文案——对应赛道红线「不碰时政」「查不到敢说不知道」。

## 镜头 5：持续盯梢（约 45s）

- 切到「持续盯梢」Tab，选镜头 2 的报告点「加入盯梢」。
- 点「立即快照」→ 展示 10 条结果快照（首次快照）。
- 讲解：到周期后会自动重搜、逐条对比、有变化会标出「有变化：新增 N 条」。
- （可选）若间隔 10 分钟能再录一次第二次快照，展示「较上次无变化/有变化」对比输出。

## 镜头 6：收尾（约 10s）

- 回首页定格，口播或字幕：作品名「AI 侦探社」+ 一句话定位（证据链侦探：结论+依据+可点开来源）。

## 录完之后

1. 检查成片：至少 1 次点开来源的动作清晰可见；查询词与留痕截图一致。
2. 存放：`docs/演示留痕/` 或直接上传（提交表单与小红书/视频号各需一份）。
3. 小红书/视频号发布时带话题：`#元宝搜索 #WaytoAGI #AI切磋大会 #1024超能Coding周末`，发布链接填入提交表单。
