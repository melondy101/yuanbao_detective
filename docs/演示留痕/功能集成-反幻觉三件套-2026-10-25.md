## 二、真实调用验证（本地生产构建）

- 环境：`npm run build` 通过（TypeScript 零错误）→ `npm run start`（localhost:3111）。
- 查询：「罗小黑战记 2 院线票房如何？后续有流媒体上线计划吗？」（页面真实发起，元宝搜索 4 轮检索）
- 结果（截图与本目录 JSON 为证）：
  - selfEval：20 条来源 / 17 个独立域名；事实 4/6 多源交叉（67%）；主动弃答 1 项（14%）；越界引用拦截 0。
  - 来源构成：官方 ×2（含苍南县人民政府门户）、百科 ×1（百度百科）、媒体 ×6（央广网/腾讯新闻/中国新闻网/新浪财经/网易等）、其他 ×11。
  - 事实区：4 个「交叉验证」章 + 2 个「单一来源」标。

## 三、过程中发现并修复的 bug

`registrableDomain()` 原实现把裸主机名当完整 URL 解析，`new URL()` 抛错后返回空串，导致所有域名判定落空（首跑全部归「其他」）。已拆分出 `registrableDomainOfHost(host)` 内核，`classifySource` 走主机名路径；修复后官方/百科/媒体分级全部正确命中。
